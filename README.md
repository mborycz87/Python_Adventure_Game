# Python Adventure Game

A text-based adventure game built in Python that immerses players in an interactive storytelling experience.

## Features

- **Interactive Storytelling** - Engaging narrative with player choices that affect the story outcome
- **Dynamic Gameplay** - Multiple paths, puzzles, and challenges to overcome
- **Text-Based Interface** - Simple yet engaging command-line experience
- **Inventory System** - Collect and manage items throughout your adventure
- **Character Progression** - Track stats, health, and abilities

## Getting Started

### Prerequisites

- Python 3.6 or higher

### Installation

1. Clone the repository:
```bash
git clone https://github.com/mborycz87/Python_Adventure_Game.git
cd Python_Adventure_Game
```

2. Run the game:
```bash
python main.py
```

## How to Play

- Read the story prompts carefully
- Enter your choices when prompted
- Manage your inventory wisely
- Explore different paths to discover multiple endings
